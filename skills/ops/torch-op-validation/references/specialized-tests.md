# 功能、内存、性能与确定性

本页的测量结果与精度验收分开。只有事先约定判据且证据齐全时才填通过；只记录测量结果时填 `MEASURED`。

| 测试 | 执行 | 报告 |
| --- | --- | --- |
| 功能 | 验证输出结构、dtype、形状、设备、别名、原位修改、返回对象、空值、预期异常。训练检查完整梯度，通信检查各 rank 及异步完成。未抛异常不足以证明功能通过。 | 断言、预期结果、实测结果、异常类型和位置 |
| 内存 | 在独占设备上用新进程测量。记录上下文初始化、输入分配、同步、峰值统计重置、算子与采样边界。使用同一范围采集候选和对照。 | 驱动侧前后差、框架预留、实际分配峰值，均以字节计；列明绝对值或增量、聚合方法和阈值来源 |
| 性能 | 使用设备事件或同步的单调主机时钟。预热和首次编译单报；明确是否包含分配、传输、同步和 Python 开销。原位输入、梯度或状态每轮恢复。 | 执行模式、计时边界、预热及测量次数、样本、p50/p95、方差与比值方向 |
| 确定性 | 对同一后端、模式、输入和初始状态重复执行。分别检查默认与严格确定性模式；记录开关是否生效，按需求加入跨进程复跑。 | 重复次数、输出及梯度的位差统计、首次失败位置、严格模式是否不支持 |

## 注意事项

- 内存只限同形状、布局、算子语义、采样策略和相同测量范围比较。不要将显存空闲量的前后差当作期间峰值、混用框架预留与已分配，或把零基线当成缺测。若有项目分级增长门槛或绝对差豁免，注明原始数值、适用指标、单位和比较符号；没有通用默认门槛。改变形状的对齐测试应独立列出。
- 设备时间与同步主机延迟分别比较；单次样本才能用于单次延迟分位数。分布式用例报告拓扑、通信量、各 rank 和最大 rank 延迟。已存输出的重放不能用于算子计时。
- 确定性验证必须重新计算结果，检查原 dtype 位模式和输出结构，不能用绝对误差容差。随机 API 区分重置 RNG 后重跑与连续取样；不能把“开关字段已配置”当作生效。ATK 支持时使用 `accuracy_dc` 及相应后端模式，与精度执行压力测试分别记录。
- 算子不支持指定模式或指标时写 `UNSUPPORTED`；尚未运行写 `NOT_RUN`；测量失败写 `ERROR` 或 `TIMEOUT`。不要因专项不适用而填零。
