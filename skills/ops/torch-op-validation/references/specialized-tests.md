# 功能、内存、性能与确定性

功能、内存、性能与确定性的结果分别记录，只有测量值时填 `MEASURED`。精度验收仅使用 2.1 适用条款，三方位差、ULP 与绝对/相对误差统计作为诊断，不增加通过门槛。

本页的专项不能替代 2.1 精度执行要求：训练反向需正反向级联，每例精度压测按 L0/L1/L2 分别完成 50/50/1000 次，支持确定性的算子重复结果须一致，设备地址预填要求见[精度与用例](precision.md)。性能预热、计时样本和专项确定性重复分别计数。

| 测试 | 执行 | 报告 |
| --- | --- | --- |
| 功能 | 验证输出结构、dtype、形状、设备、别名、原位修改、返回对象、空值、预期异常。训练检查完整梯度，通信检查各 rank 及异步完成。未抛异常不足以证明功能通过。 | 断言、预期结果、实测结果、异常类型和位置 |
| 内存 | 在独占设备上用新进程测量。记录上下文初始化、输入分配、同步、峰值统计重置、算子与采样边界。使用同一范围采集候选和对照。 | 驱动侧前后差、框架预留、实际分配峰值，均以字节计；列明绝对值或增量、聚合方法和阈值来源 |
| 性能 | 使用设备事件或同步的单调主机时钟。预热和首次编译单报；明确是否包含分配、传输、同步和 Python 开销。原位输入、梯度或状态每轮恢复。 | 执行模式、计时边界、预热及测量次数、样本、p50/p95、方差与比值方向 |
| 确定性 | 对同一后端、模式、输入和初始状态重复执行。检查默认与严格确定性模式，记录实际生效的开关。需要时跨进程复跑。 | 重复次数、输出及梯度的位差统计、首次失败位置、严格模式是否不支持 |

按 API 类型、前后向和每个 output/gradient 叶子关联这些结果，记录各端实际 dtype、输出结构和预期可微性。模型调用中 RMSNorm 的 output 与 rstd 等辅助输出分别保留，不假定各叶子 dtype 相同。跨实现三方诊断与同一后端重复执行的确定性检查分开；后者适用的 2.1 一致性要求仍须满足。

## 注意事项

- 内存只限同形状、布局、算子语义、采样策略和相同测量范围比较。不要将显存空闲量的前后差当作期间峰值、混用框架预留与已分配，或把零基线当成缺测。若有项目分级增长门槛或绝对差豁免，注明原始数值、适用指标、单位和比较符号；没有通用默认门槛。改变形状的对齐测试应独立列出。
- 分别比较设备时间和同步主机延迟。用单次调用样本计算分位数。分布式用例记录拓扑、通信量、各 rank 延迟及其最大值。计时须重新执行算子。
- 确定性测试重新执行算子，检查原 dtype 的位模式和输出结构。随机 API 分别记录重置 RNG 后复跑和连续取样。ATK 支持时使用 `accuracy_dc` 及对应后端模式，单独记录精度压力测试。
- 诊断数据使用[三方附加诊断](precision.md#三方附加诊断)中的 dtype、ULP、统计范围和缺测规则。统计剔除数与小值域错误数分别记录，不任意剔除零值。2.1 超标、执行错误与关键证据缺失标红，诊断数值较大本身不标红。
- 不支持的模式或指标标为 `UNSUPPORTED`。未运行填 `NOT_RUN`，测量失败填 `ERROR` 或 `TIMEOUT`，不适用填 `NOT_APPLICABLE`。
