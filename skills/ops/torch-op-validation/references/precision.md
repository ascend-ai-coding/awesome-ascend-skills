# 精度依据与用例设计

## 选定验收依据

按《昇腾算子精度标准 2.1》验收时，记录实际采用的修订版、原文哈希、算子类别和等级。仓库同步的商用精度文档可用于查阅通用做法。项目验收使用指定版本的原文。[CANN 商用算子精度文档](https://github.com/ascend-ai-coding/awesome-ascend-skills/blob/75ec89ce9d401be8ac95980e1c3f42f8d4315057/external/cannbot/ops/ops-precision-standard/reference/golden/COMMERCIAL_OPS_PRECISION_DOCS.md)

报告写明本轮是冒烟测试、问题定位、项目回归还是正式验收。正式验收还需核对用例规模、平台覆盖、设备实测和适用的复检要求。

## 双标杆与算子分类

- 浮点双标杆使用同一份高精度 Golden。候选和同精度对照分别计算误差，再求候选误差与对照误差的比值。通常由 CPU 计算 Golden，第三方设备提供对照。采用标准允许的组合实现时，记录适用条件和源码。
- 使用冻结输入计算 Golden，并按标准和算子语义选择计算精度。FP16/BF16 输入通常用 FP32 计算。记录权重、上游梯度、累加精度、输出 dtype 和执行模式。
- 正常值域的 MARE 和 MERE 分别取相对误差的最大值和平均值，分母为 `abs(golden) + 1e-7`。RMSE 对逐元素绝对差求均方根。用已知结果检查比较器如何处理零误差和极小误差，包括是否对分母取下限。与标准有未解释的差异时，仅报告诊断结果。
- 非计算、整数、量化及随机数算子各按对应条款判定。非计算类检查与单标杆的位一致性。整数算子同时检查返回结构及 dtype。
- 小值域按 dtype 对应的阈值统计两端超差元素。Inf、-Inf 和 NaN 按三方判定规则和设备模式检查，记录数量、符号、位置及待查原因。
- 初判失败后保留原用例，用新种子复检。公开参考要求至少 200 个样本，推荐 1000 个。进行 2000 次有放回重采样，估计中位数的 95% 置信区间。下界大于 1 时判为未通过。报告指标、样本量、分位数方法和区间。

下表列出公开商用精度文档中的普通用例规模和正常值域误差比。

| 等级 | 独立普通用例/算子 | 每种支持 dtype | 每例精度执行次数 | MARE / MERE / RMSE 比值上限 |
| --- | ---: | ---: | ---: | --- |
| L0 | 5,000 | 200 | 50 | 10 / 2 / 2 |
| L1 | 10,000 | 700 | 50 | 5 / 1.5 / 1.5 |
| L2 | 30,000 | 700 | 1,000 | 2 / 1.2 / 1.2 |

三项比值都须满足上限。保留候选和对照相对 Golden 的原始误差。使用 ATK 的 `cv_fused_double_benchmark` 时，核对三个参数的含义，并用结果已知的样本核验节点角色和比较结果。

项目另有前向逐位一致或绝对误差阈值时，用 `project-regression` 单独记录。逐位比较使用原 dtype，检查符号零、特殊值位模式和输出结构。若要求绝对误差严格小于 `1e-4`，逐元素使用 `<` 判断，相对容差为零。

## 生成与核验用例

| 来源 | 设计方法 | 证据 |
| --- | --- | --- |
| `generic` | 在合法范围对 dtype、格式、维度、标量和属性安排正交覆盖。按标准区分近零、一般均匀、正态及离群值，处理索引、缩放和通信等约束。 | 生成器修订版、配置、种子、分布和覆盖统计 |
| `model_shape` | 从训练或推理调用读取真实形状及可见属性，用公开或获准的构造数据生成用例。 | 模型或模块、阶段、调用来源、构造记录 |
| `model_dump` | 使用获准的实际调用输入，冻结张量、属性、梯度和存储关系。 | 数据来源、哈希、权限与实际覆盖范围 |
| `boundary` | 空张量、标量、上下界、非有限值、非法参数等；与普通用例分报。 | 预期行为及实际结果 |

训练记录前向、反向、优化器阶段和分布式信息。反向依赖前向缓存时，在每个执行端完成正反向级联。推理区分 prefill 和 decode，记录上下文长度、批大小和动态形状。输入清单记录 dtype、shape、stride、布局、offset、别名、标量参数和可微性。

换种子、重试和重复执行记在原用例下，边界用例另计。正式验收检查支持的 dtype、格式、设备平台及至少一百万个输出元素。L2 的泛化用例和合格模型用例按 2:1 分配。`model_shape` 能否计入模型份额，以指定版本的条款为准。报告保留计划与实测数、来源分布、排除原因和每案执行次数。

### 训练与推理样本的记录

批量采集按算子重载和调用阶段记录模型版本、模块、采样区间、调用参数和采集方式。单算子可参考以下构造用例。[任务示例](../assets/task-example.json)

训练 RMSNorm 可采集 packing 产生的不同 token 数，保存输入、权重、归一化末维和 eps。推理注意力可分别采集 prefill 和 decode 的 Q/K/V 头数、长度、布局和掩码。泛化用例再补非整齐维度、不同布局、等价参数类别及其余支持的 dtype。
